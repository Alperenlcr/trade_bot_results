**滚动窗口分析**是将固定长度的区间（例如 1 年）在整个历史上逐日滑动，并计算每个起点对应区间的收益，然后给出这些收益中的最差值、平均值和最佳值。这样您看到的不是某一次幸运的择时，而是无论何时开始都可能面对的结果范围。

本文介绍这种方法为什么重要、[首页分析面板](/zh/#analysis)中每一列的含义，以及解读结果时需要注意的地方。

## 为什么只看一个日期区间会产生误导？

“自某日起收益 X%”这样的结果，在很大程度上取决于所选的起始日期。从一轮下跌底部开始的图表会显得比实际更好，从高点开始的图表则会显得更差。这被称为**起始日期偏差**。

对趋势跟踪策略来说，这种影响更加明显。像 [ExecutorBTC](/zh/#strategy) 这样的趋势跟踪系统，大部分收益来自少数几次大行情，而在其间的横盘阶段可能出现小额亏损。因此，恰好在一轮大趋势之前或之后开始，短期结果会大不相同。

读者真正想知道的通常是：“如果我今天开始会怎样？”没有人知道今天是怎样的时点。滚动窗口分析通过测试过去**每一个**可能的起点来尝试回答这个问题。

## 滚动窗口如何计算？

方法分为四步：

1. **选择窗口长度：** 1 个月、3 个月、6 个月、1 年或 2 年。
2. **滑动窗口：** 先把窗口放在历史的最开始，然后逐日向前移动。
3. **计算每个位置的收益：** 比较窗口起点和终点的组合价值。
4. **汇总：** 给出所有这些收益中的最差值、平均值和最佳值。

![示意图：在资金曲线下方，四个相同长度的窗口相互重叠并依次向右滑动](/images/blog/rolling-window-kayan-pencere-zh.webp)

窗口之间是重叠的：如果一个 1 年窗口从今天开始，那么从明天开始的窗口几乎包含相同的日子。这种方法不是把历史切成几段，而是逐一尝试每一种“如果我在这一天开始”的情形。

### 一个简单的例子

以下数字**完全是假设的**，仅用于说明计算逻辑。假设我们把 3 个月窗口放在五个不同的起点：

| 起点 | 3 个月收益 |
|---|---|
| A | +12% |
| B | +4% |
| C | −3% |
| D | +9% |
| E | +18% |

此时面板会显示**最差**为 −3%、**平均**为 +8%、**最佳**为 +18%。实际计算中，历史上的每一天都有一个值，而不只是五个。

## 面板中的各列是什么意思？

在[分析面板](/zh/#analysis)中，先选择**起始交易**和**结束交易**，所有数据都在这个区间内计算。随后会看到：

| 列 | 含义 |
|---|---|
| **窗口** | 计算的区间长度：1 个月、3 个月、6 个月、1 年、2 年。 |
| **平均** | 该长度下所有窗口的平均收益。 |
| **最差** | 以最差择时开始时得到的收益。下方的日期区间就是那个窗口。 |
| **最佳** | 最佳择时的收益及其日期区间。 |
| **区间收益** | 所选区间从头到尾的总收益。 |
| **BTC 同期** | 同一区间内买入并持有 BTC 的收益，用于对比。 |
| **最大回撤** | 区间内组合从高点到低点的最大亏损及其日期。 |
| **盈利交易** | 盈利平仓的交易占比，以及盈利 / 亏损笔数。 |

如果所选区间短于某个窗口长度，该行会变淡显示，因为没有该长度的窗口可以计算。

## 为什么“最差”一列最重要？

平均值告诉您*通常*会发生什么，而**最差**回答的是：“如果我在最不走运的时刻入场会怎样？”在开始任何策略之前，通常最该问的就是这个问题：不是您期望什么，而是您能承受的底线在哪里。

![示意柱状图：每个起点对应的窗口收益，最差的柱子为红色，最佳的柱子为绿色，平均值为虚线](/images/blog/rolling-window-dagilim-zh.webp)

在上面的示意图中，每根柱子代表一个起点。面板并不显示整个分布，只显示两端和平均值。如果最差值为正，说明在该窗口长度下，无论过去哪一天开始，区间最终都是盈利的。

对 ExecutorBTC 而言，面板中 1 年及以上窗口的最差值在历史上始终为正。这是对过往数据的观察，并不意味着未来仍会如此。请始终在[面板](/zh/#analysis)中查看最新数值。

## 窗口长度如何影响结果？

在短窗口（1 个月、3 个月）中，结果分布很宽：最差与最佳之间差距很大，因为短短几周取决于是否出现了一轮趋势。窗口越长，好的和差的阶段越会落入同一个窗口并相互抵消，择时的影响也随之减小。

实际含义是：短暂尝试一下趋势跟踪策略就停止，结果在很大程度上取决于运气。长窗口的结果更能反映策略的整体特征。

需要注意：由于窗口相互重叠，长窗口中**独立**的观测数量很少。几年的历史可以算出数百个 2 年窗口的值，但其中大多数共享相同的日子。因此，请把长窗口的结果看作有力的参考，而不是铁律。

## 最大回撤和最差窗口是一回事吗？

不是。两者回答的是不同的问题：

- **最差窗口**看的是固定区间**结束时**的收益：“1 年后我会在哪里？”
- **最大回撤**衡量的是过程中的最大亏损：“在某个高点之后，我的账户最多跌了多少？”

![示意图：资金曲线在一个窗口内从峰值大幅回落到谷底，但最终收于起点上方，窗口收益为正](/images/blog/rolling-window-dusus-zh.webp)

一个窗口内可能出现深度回撤，但最终仍可为正。所以请同时查看两者：最差窗口反映长期结果，最大回撤反映达到这一结果所需承受的波动。承受不住回撤而中途退出的人，永远看不到窗口结束时的收益。

## 如何自己动手试一试？

1. 前往首页的[深度分析](/zh/#analysis)部分。
2. 在**起始交易**和**结束交易**菜单中选择想要研究的区间。
3. 查看**最差**一列及其下方的日期，再到[交易记录](/zh/#trades)中查看那段时间发生了什么。
4. 对比**区间收益**和 **BTC 同期**。
5. 分别选择不同的市场阶段：急跌的年份、横盘的时期以及强势上涨的阶段。观察策略在每种环境下的表现，比一个总数字能告诉您更多。

您也可以在[业绩图表](/zh/#performance)中查看长期全貌。

## 这种分析有哪些局限？

- **过去不代表未来。** 分析只涵盖已经发生过的市场环境，前所未见的环境可能带来不同的结果。
- **数据同时包含实盘和回测结果。** ExecutorBTC 自 2025 年起实盘运行，更早的阶段为回测。回测假设使用 100% 资金；实盘通常使用约 85% 资金，以留出额外的安全边际。
- **实际成本可能不同。** 手续费、资金费率和成交价格可能与计算存在偏差。
- **窗口相互重叠。** 数百个窗口值并不等于数百次独立试验。

如果您想了解跟单如何运作、资金存放在哪里，请阅读[什么是跟单交易](/zh/blog/what-is-copy-trading/)。

## 风险

没有任何策略是零风险的。ExecutorBTC 交易 BTC 合约，通常使用 2 倍杠杆；杠杆会放大亏损，短期回撤可能发生。滚动窗口分析中积极的历史结果并不保证未来收益。请仅使用您能承受损失的资金进行交易。详情请阅读[风险披露](/zh/legal/risk/)。
